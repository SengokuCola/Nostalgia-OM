# OM-3 默认 20 卷调校记录

这些档位是基于原有色卡配方的数码模拟。厂商资料用于判断调整方向，具体档位由项目选取。对照图用同一张输入分别渲染旧、新配方，未对新版进行实物胶片翻拍标定。

| 胶卷 | 本次调整与观察重点 |
|---|---|
| Portra 400 | 白平衡绿移从 +1 回到 0，检查人像脸颊和中性衣物。 |
| Portra 160 | 收回一档阴影和黑位提升，保留平滑肤色及面部轮廓。 |
| Portra 800 | 高光降一档，加入低颗粒，观察暗光人像。 |
| Gold 200 | 保留暖色，少提一档阴影，阳光下颜色更有层次。 |
| ColorPlus 200 | 减轻琥珀偏移，收回两档提影，同时提高白点一档。 |
| Ektar 100 | 恢复白点，保留鲜明色彩和细颗粒观感。 |
| Ektachrome E100 | 减少整体蓝紫偏移，降低反差、取消阴影染色，观察白墙和天空。 |
| Kodachrome 64 | 暗部压一档，加深投影片的暗调。 |
| CineStill 800T | 锁定 3200 K，取消额外白平衡偏移和分色，低颗粒，红晕 4/5。 |
| Velvia 50 | 保留高饱和及深阴影，取消高光和阴影的蓝色分色。 |
| Provia 100F | 减少全局冷偏，取消蓝青阴影，和 Velvia 50 拉开区别。 |
| Pro 400H | 减少一档蓝移，观察肤色和明亮背景之间的过渡。 |
| Pro 160S | 减少一档绿移，保留较柔和的明暗层次。 |
| NPS 160 | 收回一档高光与黑位提升，避免浅色肤质发灰。 |
| NHG II 800 | 中调少提一档，加入低颗粒。旧型号的精确颗粒量缺少标定，采用保守值。 |
| Superia 400 | 降低全局暖偏，并收回部分提影、高光和黑位，观察中性灰。 |
| Fuji C200 | 收回一档阴影提升，保留原有日光色彩。 |
| Fujifilm 200 | 琥珀偏移从 +3 降到 +1，少提一档阴影。 |
| Fujifilm 400 | 暖偏降一档，恢复白点。 |
| Natura 1600 | 恢复白点，采用中颗粒，保留低照度场景的纹理。 |
